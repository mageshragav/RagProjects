# Oracle Password Reset Guide

This document describes how to reset an Oracle account password.

## Steps

1. Navigate to the Oracle account portal.
2. Click `Forgot Password`.
3. Enter your registered email address.
4. Follow the instructions sent to your email.
5. Create a new password and confirm it.

## Notes

- Password must be at least 12 characters.
- Contact Oracle Support if you do not receive the reset email.
